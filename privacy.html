Privacy Policy

Tripkeep Keyword Research · Last updated 18 October 2026

Short version: this is a private tool used only by the owner of Tripkeep Studio. It reads keyword statistics from Google Ads. It does not collect personal data from anyone else.

1. Who we are

Tripkeep Studio is an independent digital printables shop run by Anass Kraifa, based in Morocco. Contact: anasskraifa79@gmail.com.

2. What the tool does

Tripkeep Keyword Research connects to the Google Ads API to read keyword ideas, average monthly search volumes and competition levels from the Google Ads Keyword Planner. We use these numbers to decide which printable products to design.

3. Data we access

  • Google account authorization: when the shop owner signs in with Google, we receive an OAuth refresh token for the Google Ads API scope (adwords). It is stored only on the owner's own computer and is used only to request keyword data for our own Google Ads account.
  • Keyword statistics: search volumes, trends, competition and bid estimates returned by Google for the keywords we enter. This is aggregated data and contains no personal information.

4. Data we do not collect

The tool has no public sign-up and no other users. We do not collect names, emails, payment details, cookies, analytics or any information about website visitors or Etsy shoppers. This website itself uses no tracking.

5. How we use Google user data

Google user data is used only to provide the keyword research feature described above. We do not sell it, share it with third parties, use it for advertising, or use it to train AI models. Our use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

6. Storage and security

Credentials stay on the owner's personal computer and are never published. Keyword results are kept in private notes and spreadsheets used for product planning.

7. Removing access

Access can be revoked at any time from Google Account permissions. When access is revoked, the stored refresh token stops working and is deleted.

8. Changes

If this policy changes, we will update this page and the date above.

9. Contact

Questions or requests: anasskraifa79@gmail.com.
